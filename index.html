RONIN

A personal assistant that tells one person only what is worth telling.

RONIN is a personal project, written and run by one person for their own use. It watches the owner's code repositories and Gmail mailbox, decides what actually needs attention, and reports it — interrupting rarely, and doing nothing on its own that cannot be undone or that has not been approved first.

What it does

  • Reads the owner's Gmail (sender, subject, date and a short snippet) to notice, for example, a reply that has been waiting for weeks.
  • Reads the owner's local code repositories to notice unpushed work or an exposed secret.
  • On the owner's explicit approval, can move old bulk mail to Gmail's Trash. It never permanently deletes anything.

Who it is for

Only its owner. RONIN is not offered to the public, has no other users, and runs on the owner's own computer. The Google sign-in exists so that RONIN can read the owner's own mailbox.
